enum Consent : Enum<Consent>

Enum class representing the possible consent states for user data collection and tracking. This class is used to manage and track user consent preferences in compliance with privacy regulations and user choices.

OPT_IN

User has explicitly opted in to data collection and tracking. This state indicates that the user has given permission for their data to be collected and used according to the CDP's privacy policy.

OPT_OUT

User has explicitly opted out of data collection and tracking. This state indicates that the user has declined permission for their data to be collected and the SDK will respect this choice by limiting data collection.

PENDING

Default consent state prior to being set. This is the initial state before the user has made an explicit choice. This value may not be manually set and is used internally by the SDK.
