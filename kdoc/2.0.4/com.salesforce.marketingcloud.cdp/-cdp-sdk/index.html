CdpSdk

class CdpSdk : CdpModuleInterface, CdpAuthenticator.CdpAuthenticatorListener

Main CDP SDK class that provides functionality for Customer Data Platform integration. This class manages user consent, event tracking, session management, and location services. It implements the CdpModuleInterface and handles authentication through CdpAuthenticatorListener.
